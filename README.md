# 전주BURI — 형태와 놀이를 수집하는 디저트 편집숍

HOME · BRAND · COLLECTION · NOTICE

현재 사이트는 9개 제품의 **기획 시안**과 제품·패키지의 관점을 소개하는 정적 아카이브입니다. 가격, 재고, 판매 일정, 결제 기능은 포함하지 않습니다.

## 파일 구조

- `index.html`: HOME / BRAND / COLLECTION / NOTICE 및 상품 상세 대화상자
- `products.js`: 기존 9개 제품 명칭·설명, 기획 관점, 원본 이미지의 표시 영역, 관련 제품
- `app.js`: 페이지 이동, 필터, 상세 팝업, 포커스 복귀, 스크롤 전환
- `styles.css`: 공통 글자·색·버튼·반응형 레이아웃
- `assets/`: 기존 상품 원본 9장과 제공된 로고 원본
- `DESIGN-NOTES.md`: 디자인 기준, 자료 사용 내역, 추가 제작·확인 목록

## 이동과 상세

- `#home`, `#brand`, `#shop`, `#notice`
- `#shop/chocolate`, `#shop/cookie`, `#shop/tea`
- `#shop/product/giwa-collection` 등 제품 ID를 사용한 직접 상세 링크

메뉴의 COLLECTION은 기존 `#shop` 주소를 유지합니다. 상세 팝업의 닫기 버튼과 Escape는 원래 선택 지점으로 돌아가며, 하단에는 컬렉션 복귀 버튼이 있습니다.

## 이미지와 콘텐츠

원본 이미지의 제품 형태, 색상, 패키지 표기는 변경하지 않습니다. 합성 보드의 제품 장면·구조 설명은 CSS 표시 영역을 나누어 사용합니다. 추가 이미지가 필요한 부분은 `DESIGN-NOTES.md`에 명시했습니다.

기와 · 문양은 사용자의 확인에 따라 수량을 언급하지 않고 문양 중심으로 설명합니다. 쿠키탑의 조립도는 기획 개념이며 검증된 제조 사양으로 안내하지 않습니다.

## 실행과 배포

별도 패키지 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열 수 있습니다.

Cloudflare Pages는 GitHub `main` 브랜치에 연결되어 있습니다. 저장소 최상단을 배포하며, 새 파일인 `products.js`를 함께 포함해야 합니다. Framework preset은 None, 출력 디렉터리는 `.`입니다.

## 확인 범위

360 / 390 / 430px 모바일 및 768 / 1280 / 1440px 화면에서 주요 페이지를 확인합니다. 필터별 수량은 전체 9개, 초콜릿 5개, 쿠키 3개, 차 1개입니다. 키보드 메뉴·필터·상세 진입·닫기, Escape, 상세 내부 관련 제품, 기존 카테고리 주소, 동작 줄이기 설정을 점검합니다.
